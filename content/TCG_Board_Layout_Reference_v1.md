# The Crazy Game — Board Layout Reference (v1 — CONFIRMED)

**Status: Confirmed.** Built directly from a complete space-by-space description. Cross-validated against every previously-established fact in the Master Rules Reference (Crazy Beach Loop's both branches, the Spiral Portal's position, the Risky Rapids (−1) space position, the Bridge's two halves) — all matched exactly, with zero contradictions found.

**Legend:** B = Blank · S = Star · LP = Life Preserver · M = Mud · (−1) = Lose LP space · Smiley/Frowny numbers reflect board order of their *origin* (send) space, independently numbered per type.

## Full Path, Start to Castle

### Segment 1 — Start to Mud Pond Loop junction
Start → B, B, B, B, S, **Smiley 1 (send)**, B, LP, B, B, M → **[Junction: Star]**

### Segment 2 — Mud Pond Loop (Section 4)
**Right branch:** B, B, M, **Frowny 1 (entry)**, B, S, B, M, B, LP *(convergence)*
**Left branch:** B, B, B, B, B **[Frowny 5 entry]**, M, S, B, B, B, LP *(convergence — same space as right branch)*

### Segment 3 — Mud Pond convergence to Crazy Beach Loop junction
**Smiley 2 (send)**, B, *(pass under the Bridge here — not a counted space, see Section 6)*, S, M, B **[Frowny 3 entry]**, B, **[2 OR 3 escape box]**, **Smiley 3 (send)**, B, S → **[Junction: Blank]**

### Segment 4 — Crazy Beach Loop (Section 5) — matches existing documentation exactly
**Right/Lower branch:** B, S, B, S *(+ Lower Crazy Beach entry point)*, B, S, B, LP, **Checkered Portal #1** *(only triggers if landed on exactly — see note below)*
**Left/Upper branch:** B, B, S, B, S *(+ Upper Crazy Beach entry point)*, LP, B, **Smiley 4 (send)**, B, B, **Checkered Portal #1** *(same space, same caveat)*

**Important: this Portal is not a mandatory checkpoint.** Both branches' independent numbering ends at this same space, but like any other space, the Portal only triggers if a roll lands a player exactly on it (Section 11). Most rolls will overshoot it — those players simply continue straight into Segment 5 below, on the single already-merged path, without ever teleporting. Only a player who lands exactly on this space gets sent immediately to Checkered Portal #2 (Segment 7).

### Segment 5 — Continuing past Checkered Portal #1's space (for players who don't land exactly on it) to the Crazy River junction
M, B, B, S, B *(shared space: **Smiley 4 entry** + **Frowny 2 entry**)*, LP, B, **[Swap space]**, B → **[Junction: Blank — Crazy River branches off at ~90°]**

### Segment 6a — Down Crazy River (Sections 4, 13)
B, B, LP, S, B, B *(Risky Rapids offshoot point)* → B, B, B, LP *(convergence — dry land, not water; this is the point Crazy River connects back to the main path, not part of the water hazard itself)*

**Risky Rapids offshoot (Section 13):** B, B, B, (−1), LP, B, (−1), B, **Shore space** *(Crazy Coin + Sand Dollar in tournament)*

*Note: the Crazy Coin Stack sits physically between Crazy River and the main path.*

### Segment 6b — Main path (skipping Crazy River)
S, B, M, B, **Fish Pond**, **Spiral Portal #1**, B, S, M, B *(**Smiley 1 entry**)*, B, LP *(convergence — same space as Segment 6a's end)*

### Segment 7 — Convergence to start of Sharky Shores
**Frowny 1 (send)**, S, **[5 OR 6 escape box]**, B, **Frowny 2 (send)**, **Checkered Portal #2**, S, B *(**Smiley 2 entry**)*, LP, B *(**Smiley 3 entry**)*, **Bridge (actual space here — see Section 6)**, B, **Spiral Portal #2**, B *(**Frowny 4 entry**)*, S, **Frowny 3 (send)**, M, **[1 OR 4 escape box]**, LP, B

### Segment 8 — Sharky Shores to Castle (Section 7)
*(Stepping-stone spaces function as normal Blank spaces, just visually distinct)*
B, B, **Frowny 4 (send)**, (−1), **Frowny 5 (send)**, (−1), B, Whirlpool, Whirlpool, Whirlpool → **CASTLE**

## Design Note (Resolved)

The (−1) spaces are mechanically identical everywhere — confirmed no rules difference between Sharky Shores and Risky Rapids. The visual difference is intentional art design: in Risky Rapids, no player is ever there without a Life Preserver (it's required to enter, barring the narrow exact-roll exception), so the (−1) icon sits boldly in the middle of the space. In Sharky Shores, a player *can* legitimately be Life-Preserver-less and still step onto those spaces, so the icon is placed off to the side of what still reads visually as an ordinary, steppable stepping stone — keeping the art consistent with the fact that any player can land there, even though the underlying rule (unaffected if you have no Life Preserver) already handles this correctly regardless of art style.
